# Incident Response

## Purpose

This document defines the standard process for diagnosing, responding to, documenting, and resolving production incidents.

## Objectives

- Restore service quickly.
- Minimize downtime.
- Identify root causes.
- Document lessons learned.
- Prevent recurrence.

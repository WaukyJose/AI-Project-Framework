# Operations

Operational procedures, scripts, monitoring guidance, and troubleshooting references for framework-managed projects.

- `Deployment/` - Deployment procedures and verification.
- `Monitoring/` - Health, logging, and service monitoring.
- `Troubleshooting/` - Reusable production issue guides.

Framework responsibilities remain separate:

- `Core/` defines principles and standards.
- `Templates/` contains reusable blank artifacts.
- `Projects/` contains project-specific documentation.
- `Operations/` contains runbooks, procedures, and troubleshooting guidance.

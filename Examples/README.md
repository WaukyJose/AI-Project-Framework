# Examples

## Purpose

The Examples directory demonstrates how the AI Project Framework is applied in practice.

Unlike Templates, which provide reusable structures, Examples contain completed documents illustrating recommended practices.

Examples are intended to help users understand how framework concepts should be implemented.

---

## Relationship to Other Directories

| Directory | Purpose                               |
| --------- | ------------------------------------- |
| Core      | Defines the methodology               |
| Templates | Provides reusable document structures |
| Examples  | Demonstrates completed documents      |
| Projects  | Contains real-world implementations   |

---

## Guiding Principle

Examples should be:

- Complete
- Easy to understand
- Based on framework standards
- Independent of any specific project whenever possible

Real projects may later replace or improve these examples as better practices emerge.

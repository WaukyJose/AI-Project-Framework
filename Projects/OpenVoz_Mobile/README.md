# OpenVoz Mobile

OpenVoz Mobile is the mobile application project within the AI Project Framework for the OpenVoz product.

It exists to define the documentation, architecture direction, and planning baseline required to support current and future AI educational mobile applications.

The project initially supports the OpenVoz mobile initiative, but it is structured for reuse across additional products rather than for a single application alone.

## Current Status

Active planning and architecture.

## Current Focus

- Shared mobile platform architecture
- OpenVoz mobile foundation
- Cross-platform planning for Android, iOS, and tablets
- Reusable documentation for future mobile educational products

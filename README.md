# AI Project Framework

This repository is the source of truth for projects managed with the AI Project Framework.

It contains framework governance, shared operating guidance, and project-specific documentation for active AI initiatives.

## Repository Areas

- `Core/` - Framework philosophy, lifecycle, structure, workflow, quality standards, and engineering guidance.
- `Projects/` - Project-specific documentation for active framework-managed projects.
- `Operations/` - Shared deployment, monitoring, and troubleshooting guidance at the framework level.
- `Templates/` - Reusable templates and initialization materials.
- `Examples/` - Example materials when available.
- `Archive/` - Retired or historical framework materials.

## Active Projects

- `Projects/OpenVoz_Mobile/` - OpenVoz mobile application project within the AI Project Framework.
- `Projects/OpenVoz/` - Reference production AI speaking platform.
- `Projects/ReadingStrategyCoach/` - AI-powered mobile reading-learning application.
- `Projects/ConjuncTool_Resubmission/` - Project-specific materials for the ConjuncTool resubmission effort.
